## 为什么叫「不可以已」

名字出自《荀子・劝学》：**学不可以已**。

学习这件事没有终点，停下来就等于退步。做这个博客也是同样的心态：把折腾过的东西写下来，既是整理，也是继续往前走的记录。

## 这个站会放什么

- **技术文章**：Vue、Vite、GitHub Pages 这类前后端折腾笔记
- **小工具**：自己写的一些实用小玩意
- **Demo**：各种好玩的页面和小游戏，比如「修狗巨人」

## 怎么发布一篇文章

文章就是项目里的一个 Markdown 文件，写完推送就自动上线：

```bash
git add .
git commit -m "发布新文章"
git push origin master
```

> 保持好奇，持续折腾。
