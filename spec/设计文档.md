# 不可以已 · 设计文档

> 版本：v1｜更新日期：2026-10-11
> 设计文件：`spec/ui/design.pen`（V3 方案共 14 个画板）
> 相关文档：[需求文档](./需求文档.md)、[技术方案文档](./技术方案文档.md)

## 1. 设计方向

**极简、编辑感、大留白。** 参考 oiloil.org 的排版逻辑（窄列、大标题、编号分区、单色 + 一个小圆点强调色），但把桌面内容列放宽到适合电脑屏幕的尺寸，避免照抄造成的「手机版放大」观感。

整体气质：干净、克制、有设计感，但不喧哗；靠字号对比和留白建立秩序，而不是靠颜色和阴影。

## 2. 设计原则

1. **内容优先**：去掉一切非必要的装饰、色块、阴影、渐变
2. **单色体系 + 一个强调色**：白底、黑灰文字，仅用一个珊瑚红作点缀
3. **强烈的字号对比**：大标题极大、说明文字极小，中间层级少
4. **首页分两屏**：第一屏只放品牌与大标题，滚动后的内容另起一屏
5. **移动端不是缩小的桌面**：手机版单独排版，长内容改为堆叠行

## 4. 栅格与响应式

| | 桌面 | 手机 |
| --- | --- | --- |
| 画板宽度 | 1920 | 390 |
| 内容列宽 | 1280 | 350 |
| 左右留白 | 320 | 20 |
| 建议断点 | ≥1024 用桌面版式；&lt;1024 用手机版式并放宽留白 | — |

实现时内容列建议用 `max-width` + 居中，而不是固定 1280px，保证 1440 宽屏幕也不会贴边。

## 5. 组件规范

| 组件 | 规范 |
| --- | --- |
| 页头 | 左侧：9px 珊瑚圆点 + 品牌名「不可以已」；右侧：四项导航，间距 24；上边距 32；当前页导航用主文字色，其余用次级色 |
| 页脚 | 仅一行「© 2026 不可以已」，弱化色，上边距 60 |
| 分区标签 | 等宽字体，形如 `01 / 作品`，弱化色 + 宽字距 |
| 列表行 | 上边线在列表容器、下边线在每行；行内左侧「编号 + 标题」，右侧「元信息 + ↗」，行高 26（桌面）/ 16（手机） |
| 插画位 | 桌面 140×184、手机 100×136，3:4 比例，圆角 22 / 16，位置在大标题行末 |
| 代码块 | 深色底、圆角 14、等宽字体、内边距 24 |
| 引用 | 左侧 3px 珊瑚竖线 + 灰字 |

## 6. 页面规范

### 6.1 首页（两屏）

- **第一屏**：页头 + 大标题（记录与分享 / 技术与工具。，第二行行末内嵌插画）+ 一行「前端工程师」+ 底部「↓ 下滑」。除上述内容外**不留任何其他元素**，标题区与提示之间用弹性间距撑满整屏。
- **第二屏**：`01 / 作品`（3 行）+ `02 / 文章`（3 行）+ 页脚。

### 6.2 作品列表 `/works`

页面标题「作品」+ 一行说明，随后 5 行：JSON 格式化、时间戳转换、图片压缩、修狗巨人、更多作品（右侧标注类型或状态）。

### 6.3 文章列表 `/articles`

页面标题「文章」+ 一行说明，随后按时间倒序的文章行；桌面版为「编号 + 标题 + 日期」，手机版改为「标题在上、日期在下」的堆叠行。

### 6.4 文章详情 `/articles/<slug>`

返回链接 → 文章标题 → 日期与标签 → 分隔线 → 正文。正文列宽 860px（比列表窄，保证阅读行长合适），包含段落、小标题、代码块、引用四种基本块。

### 6.5 小游戏 `/games`

页面标题「小游戏」+「打开即玩，不用登录。」，随后 3 行：修狗巨人（可玩）、更多小游戏（开发中）、想玩什么（告诉我）。

### 6.6 关于 `/about`

页面标题「关于」→ 一段自我介绍 → `联系 / ELSEWHERE` 分区 → 3 行联系方式（GitHub、邮箱、微信）。联系方式只在此页出现。

## 7. 交互与动效

- 列表行悬停：标题颜色变强调色，右侧箭头右上方位移 2px（120ms）
- 导航悬停：次级色 → 主文字色
- 首屏下滑提示：轻微上下浮动循环
- 动效原则：只用位移与透明度，不用缩放、模糊、发光；时长 120–200ms
- 后续若加入滚动动画，只对首屏标题做一次性淡入上移
