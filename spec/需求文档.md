## 1. 项目背景

博主是一名前端程序员，希望把个人网站重新设计，用来打造个人品牌、沉淀技术输出、分享自己写的小工具，并在流量增长后获得一定收入。

### 1.1 现状

- 线上地址：https://windinfur.github.io/
- 现有技术：Vue 3 + Vite + vue-router 的单页应用，纯 CSS
- 已有内容：首页、Markdown 文章系统、独立小游戏「修狗巨人」
- 主要问题：页面在浏览器端渲染，搜索引擎与社交分享拿不到内容；视觉与信息结构需要重做

### 1.2 环境

| 项 | 版本 |
| --- | --- |
| Node | v22.23.1（nvm 管理） |
| npm | 10.9.8 |

## 2. 目标与非目标

### 2.1 目标

1. **品牌**：访客在 10 秒内知道「我是谁、我做什么、有什么作品」
2. **内容**：写作流程简单，新增 Markdown 文件并推送即可发布
3. **作品**：工具、Demo、小游戏各有独立入口，可直接使用和分享
4. **增长**：页面能被搜索引擎正确收录，分享时有正确的标题与摘要
5. **变现**：具备接入广告的基础条件（内容量、合规页面、自定义域名）

### 2.2 非目标（本期不做）

- 后台管理系统、在线编辑器
- 用户注册与登录
- 数据库与服务端 API
- 多语言版本
- 深色模式（浅色版确认上线后再说）

## 3. 目标用户

| 用户 | 诉求 | 对应设计 |
| --- | --- | --- |
| 技术同行、潜在雇主 | 快速了解能力与作品 | 首页定位语、作品列表、关于页 |
| 搜索技术问题的开发者 | 快速找到答案 | SEO、清晰的文章结构、代码块 |
| 工具与游戏使用者 | 拿来就用 | 独立入口、无需登录、移动端可用 |
| 博主自己 | 记录与检索 | 标签、归档、后续的站内搜索 |

## 4. 网站定位

> 一句话：一个前端程序员的技术笔记与工具箱。

## 5. 内容规划

| 类型 | 说明 | 更新节奏 |
| --- | --- | --- |
| 文章 | 前端工程化、Vue / JavaScript 实战、踩坑记录、性能优化 | 建议每周 1 篇 |
| 作品 | 自己写的小工具、Demo | 不定期 |
| 小游戏 | 交互型小游戏，如「修狗巨人」 | 不定期 |
| 关于 | 自我介绍、技能、联系方式 | 长期维护 |

## 6. 页面与功能需求

### 6.1 页面清单（P0，首版必须有）

| 页面 | 路由 | 功能点 |
| --- | --- | --- |
| 首页 | `/` | 两屏结构：第一屏只有品牌与大标题，第二屏为作品与文章列表 |
| 作品 | `/works` | 作品列表，每项可进入详情/直接使用 |
| 文章列表 | `/articles` | 按时间倒序，显示标题与日期 |
| 文章详情 | `/articles/<slug>` | Markdown 正文、代码高亮、返回入口 |
| 小游戏 | `/games` | 小游戏列表，点击即玩 |
| 关于 | `/about` | 简介、技能、联系方式（GitHub / 邮箱 / 微信） |

### 6.2 通用能力（P0）

- 响应式：桌面（1920 设计宽度）与手机（390）两套版式
- 页头导航：作品 / 文章 / 小游戏 / 关于，当前页高亮
- SEO：每页真实 HTML、标题与描述、分享卡片、sitemap
- 订阅：RSS
- 部署：推送即自动构建发布

### 6.3 后续迭代（P1）

- 站内搜索
- 评论（如基于 GitHub Discussions 的 giscus）
- 文章目录（TOC）、上一篇 / 下一篇
- 访问统计
- 深色模式

### 6.4 更远期（P2）

- 广告位（内容型广告，避免干扰阅读）
- 邮件订阅
- 系列专栏、专题页

## 7. 非功能需求

| 维度 | 要求 |
| --- | --- |
| 性能 | 手机 4G 首屏尽量 2 秒内；默认不加载多余 JS；图片懒加载 |
| SEO | 每页独立 HTML、语义化标签、结构化数据、sitemap、RSS |
| 兼容 | 现代浏览器近两年版本；移动端优先 |
| 可访问性 | 键盘可操作、对比度达标、图片有替代文本 |
| 可维护 | 新增文章 = 新增 md + 推送，不改代码 |
| 成本 | 优先免费额度；域名年费可接受 |

## 8. 已确认决策

## 11. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| GitHub Pages 国内访问慢 | 流量与广告收入受限 | 自定义域名 + 换托管；面向国内则考虑国内云 + 备案 |
| 更换框架导致旧链接失效 | 已分享链接打不开 | 迁移时保留旧路径或做跳转页 |
| 广告审核门槛 | 早期无法变现 | 先积累原创内容并补齐隐私政策等页面 |
| 设计返工 | 浪费时间 | 先确认设计稿再进入编码 |
